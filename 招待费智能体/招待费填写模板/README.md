# 业务招待费填写模板（V9.0 配套）

> 依据：《中国移动广东公司清远分公司业务招待费管理办法（V9.0）》
> 发布日期：2025年7月9日

## 模板文件清单

| 文件名 | 说明 |
|--------|------|
| `01_标准速查表.xlsx` | 各类招待标准速查，含酒水/纪念品限额 |
| `02_对外业务招待申请单.xlsx` | 对外（商务/外事/其他公务）事前申请单 |
| `03_内部业务招待申请单.xlsx` | 内部业务招待事前申请单 |
| `04_酒水纪念品明细表.xlsx` | 酒水采购/纪念品赠送明细 |
| `05_报销明细表.xlsx` | 招待费报销明细及支撑材料清单 |
| `06_节假日报备表.xlsx` | 国家法定节假日前后业务招待报备 |
| `07_场景对照手册.md` | 对内/对外各场景标准对照手册 |

## 快速使用

1. 先查 **01_标准速查表** 确认本次招待标准上限
2. 填写对应 **申请单**（对外用 02，内部用 03）
3. 涉及酒水/纪念品，补充 **04_酒水纪念品明细表**
4. 报销时填写 **05_报销明细表** 并附支撑材料
5. 节假日期间安排招待，额外填写 **06_节假日报备表**
