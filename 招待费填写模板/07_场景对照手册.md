# 业务招待场景对照手册

> 依据：《中国移动广东公司清远分公司业务招待费管理办法（V9.0）》
> 发布日期：2025年7月9日

---

## 一、场景分类总览

业务招待分为 **对外业务招待** 和 **内部业务招待** 两大类。

| 大类 | 子类 | 适用场景 |
|------|------|----------|
| **对外** | 商务招待 | 商业谈判/合作中招待客户、合资合作方、经贸联络考察团组 |
| **对外** | 外事招待 | 招待外宾或其他外籍关系人员 |
| **对外** | 其他公务招待 | 招待党政军机关工作人员（参照《党政机关国内公务接待管理规定》） |
| **内部** | 内部业务招待 | 集团公司内部上下级单位之间、平级单位之间的公务招待 |
| **内部** | 工作餐 | 日常公务活动期间用餐 |

---

## 二、对外业务招待场景详解

### 场景 1：商务招待 - 宴请客户

| 项目 | 省管中层 | 市管中层 | 其他人员 |
|------|----------|----------|----------|
| **宴请标准** | ≤400元/人·次 | ≤300元/人·次 | ≤200元/人·次 |
| **酒水标准** | 白酒≤400元/500ml，红酒≤400元/750ml | 白酒≤300元/500ml，红酒≤300元/750ml | 白酒≤200元/500ml，红酒≤200元/750ml |
| **能否上烟酒** | 可以（非高档） | 可以（非高档） | 可以（非高档） |
| **能否赠送纪念品** | ≤400元/人·次 | ≤300元/人·次 | ≤200元/人·次 |
| **陪餐人数** | 对象≤5人可等；>5人部分陪餐≤1/2 | 同左 | 同左 |
| **适用模板** | 02_对外业务招待申请单 + 04_酒水纪念品 | 同左 | 同左 |

**禁止事项：**
- 不得提供高档酒水
- 不得提供鱼翅、燕窝等高档菜肴
- 不得安排私人会所及高消费场所
- 不得用公款购买香烟

---

### 场景 2：商务招待 - 赠送纪念品

| 项目 | 省管中层 | 市管中层 | 其他人员 |
|------|----------|----------|----------|
| **纪念品标准** | ≤400元/人·次 | ≤300元/人·次 | ≤200元/人·次 |
| **内容要求** | 企业形象/企业文化/社会责任/地域文化 | 同左 | 同左 |
| **禁止赠送** | 现金、购物卡、会员卡、有价证券、贵重物品 | 同左 | 同左 |
| **适用模板** | 02_对外业务招待申请单 + 04_纪念品明细 | 同左 | 同左 |

**禁止赠送：**
- 现金、购物卡、会员卡、商业预付卡
- 各种有价证券、支付凭证、贵重物品
- 名贵土特产
- 高于标准规定的纪念品

---

### 场景 3：外事招待 - 宴请外宾

| 项目 | 省管中层 | 市管中层 | 其他人员 |
|------|----------|----------|----------|
| **宴请标准** | ≤400元/人·次 | ≤300元/人·次 | ≤200元/人·次 |
| **酒水标准** | 白酒≤400元/500ml，红酒≤400元/750ml | 白酒≤300元/500ml，红酒≤300元/750ml | 白酒≤200元/500ml，红酒≤200元/750ml |
| **纪念品标准** | ≤400元/人·次 | ≤300元/人·次 | ≤200元/人·次 |
| **适用模板** | 02_对外业务招待申请单 + 04_酒水纪念品 | 同左 | 同左 |

**特殊要求：**
- 遵守外事工作规定和保密要求
- 优先在社会公共场所安排
- 不得提供用野生保护动物制作的菜肴

---

### 场景 4：其他公务招待 - 招待党政军机关

| 项目 | 省管中层 | 市管中层 | 其他人员 |
|------|----------|----------|----------|
| **宴请标准** | ≤200元/人·次 | ≤200元/人·次 | ≤150元/人·次 |
| **酒水标准** | 白酒≤200元/500ml，红酒≤200元/750ml | 白酒≤300元/500ml，红酒≤300元/750ml | 白酒≤200元/500ml，红酒≤200元/750ml |
| **能否赠送纪念品** | **不得赠送** | **不得赠送** | **不得赠送** |
| **适用模板** | 02_对外业务招待申请单 | 同左 | 同左 |

**特殊要求：**
- 参照《党政机关国内公务接待管理规定》执行
- 各项标准从严把握
- 不得赠送纪念品

---

### 场景 5：商务招待 - 安排住宿

| 项目 | 标准 |
|------|------|
| **住宿原则** | 安全、舒适，不追求奢华 |
| **房型** | 一般单间或标准间；特别重要人员可普通套间 |
| **标准** | 参照《差旅费管理办法》同城市相应级别 |
| **适用模板** | 02_对外业务招待申请单 |

---

### 场景 6：商务招待 - 安排用车

| 项目 | 要求 |
|------|------|
| **原则** | 统一管理、定向保障、经济适用、节能环保 |
| **优先** | 公司自有车辆 |
| **租用** | 须与资质合格、运营规范的汽车租赁公司签订合同 |
| **禁止** | 公车私用、私车公养 |
| **要求** | 集中乘车，减少随行车辆 |
| **适用模板** | 02_对外业务招待申请单 |

## 三、内部业务招待场景详解

### 场景 7：内部业务招待 - 集团公司/外省单位到访

| 项目 | 省管中层 | 市管中层 | 其他人员 |
|------|----------|----------|----------|
| **用餐标准** | ≤150元/人·次 | ≤150元/人·次 | ≤100元/人·次 |
| **能否上烟酒** | **不得上** | **不得上** | **不得上** |
| **能否赠送纪念品** | **不得赠送** | **不得赠送** | **不得赠送** |
| **陪餐人数** | 对象≤10人≤3人；>10人≤1/3 | 同左 | 同左 |
| **适用模板** | 03_内部业务招待申请单 | 同左 | 同左 |

**适用条件：**
- 集团公司或外省兄弟单位到访清远公司（**不同城**）
- 原则上不安排内部招待，可视情况安排工作餐

---

### 场景 8：内部业务招待 - 同城单位之间

| 项目 | 要求 |
|------|------|
| **能否安排内部招待** | **原则上不安排** |
| **能否安排工作餐** | 可视情况安排 |
| **工作餐标准** | 参照食堂正常标准或差旅伙食补贴 |
| **工作餐次数** | 可按实际工作需求安排 |
| **适用模板** | 无需申请单，直接安排工作餐 |

---

### 场景 9：工作餐 - 日常公务

| 项目 | 要求 |
|------|------|
| **用餐地点** | 原则上在单位食堂 |
| **用餐形式** | 优先采用自助形式 |
| **标准** | 参照所在单位食堂正常标准或差旅伙食补贴 |
| **能否上烟酒** | **不得上** |
| **适用模板** | 无需申请单 |

---

### 场景 10：工作餐 - 外出调研无法在食堂用餐

| 项目 | 要求 |
|------|------|
| **用餐方式** | 参照食堂标准就近安排 |
| **标准** | 同食堂正常标准 |
| **出差人员** | 领取差旅伙食补贴的应交纳相关费用 |
| **适用模板** | 无需申请单 |

---

## 四、陪餐人数速查

### 对外业务招待（第十二条）

| 招待对象人数 | 陪餐人数上限 |
|-------------|-------------|
| ≤5人 | 可等量陪餐 |
| 6人 | 最多 5+1=6人 |
| 7人 | 最多 5+2=7人 |
| 8人 | 最多 5+1.5→6人 |
| 10人 | 最多 5+2.5→7人 |
| 15人 | 最多 5+5=10人 |
| 20人 | 最多 5+7.5→12人 |

**公式：** 陪餐人数 = 5 + min(对象人数-5, (对象人数-5)/2) = 5 + (对象人数-5)/2（取整）

### 内部业务招待（第十三条）

| 招待对象人数 | 陪餐人数上限 |
|-------------|-------------|
| ≤10人 | 最多 3人 |
| 11人 | 最多 3人 |
| 12人 | 最多 4人 |
| 15人 | 最多 5人 |
| 20人 | 最多 6人 |
| 30人 | 最多 10人 |

**公式：** 陪餐人数 = min(3, 对象人数)（≤10人时）；对象人数×1/3（>10人时，取整）

## 五、列支范围与禁止事项

### 可列支范围（第八条）

| 项目 | 说明 |
|------|------|
| 宴请 | 宴请客户、合作伙伴、来宾，或提供工作餐 |
| 纪念品 | 商务/外事招待活动中赠送的纪念品 |
| 用车 | 商务招待用车保障服务 |
| 住宿 | 商务招待确需安排的住宿 |
| 零星开支 | 茶叶、水果等 |

### 禁止事项汇总

| 条款 | 禁止事项 |
|------|----------|
| 第十四条 | 私人会所、高档娱乐场所、野生保护动物菜肴、鱼翅燕窝、香烟、高档酒水、珍稀药材、天价茶叶、名贵木材、珠宝玉石、名瓷名画 |
| 第十五条 | 批量购买业务招待用酒 |
| 第十六条 | 以业务招待名义变相旅游 |
| 第十七条 | 用公款相互走访、送礼、宴请等拜年活动；上下级/部门之间用公款送礼 |
| 第十八条 | 滥用赠送、回馈手段扰乱市场经营秩序 |
| 第十九条 | 支付个人负担费用；向下属单位摊派/转嫁费用 |
| 第二十条 | 赠送现金、购物卡、会员卡、有价证券、贵重物品 |
| 第二十三条 | 节假日期间一般不安排业务招待 |
