# 业务招待费审核 Skill

## 用途

用于审核业务招待费报销批次的合规性，确保所有单据符合公司规定。

## 审核标准

### 一、招待标准

| 项目 | 标准 |
|------|------|
| 招待人数 | 按实际公务需要确定 |
| 陪同人数 | 原则上不超过招待人数 |
| 人均费用 | 按当地消费水平及公司标准执行 |
| 纪念品 | 原则上不得赠送，确需赠送的按标准执行 |

### 二、禁止性规定

1. **不得超标准招待**：人均费用、陪同人数、总金额不得超过规定标准
2. **不得违规赠送纪念品**：原则上禁止，特殊情况需审批
3. **不得拆分报销**：不得将同一招待事项拆分多次报销以规避审批
4. **不得虚报冒领**：招待事项必须真实，单据必须合法合规
5. **不得重复报销**：同一事项不得重复报账
6. **不得无公函招待**：公务招待必须有公函或审批表作为依据

### 三、单据要求

每个批次必须包含以下单据：

| 序号  | 单据类型    | 是否必须 | 说明                                    |
| --- | ------- | ---- | ------------------------------------- |
| 1   | 业务招待申请单 | 是    | 事前申请，包含招待对象、类型、日期、人数等                 |
| 2   | 业务招待审批表 | 是    | 完整审批流程记录                              |
| 3   | 发票      | 是    | 合法有效的增值税发票                            |
| 4   | 支付凭证    | 是    | 银行转账记录或支付平台交易明细，交易时间精准到时分秒，有交易单号，商户单号 |
| 5   | 确认单     | 是    | 报账付款信息确认单                             |
| 6   | 往来公函    | 是    | 公务招待的公函依据                             |
| 7   | 单位认证    | 是    | 招待单位资质认证信息                            |

## 风险点

### 高风险

- 招待事项不真实或无法核实
- 发票异常（连号、重复、假发票）
- 支付凭证与发票金额不匹配
- 招待对象与公函不一致
- 超标准招待（人均费用、陪同人数超标）

### 中风险

- 申请单与审批表信息不一致
- 招待日期与发票日期不匹配
- 缺少必要的支撑单据
- 报账时间距离招待时间过长

### 低风险

- 单据填写不完整
- 审批流程不规范
- 备注信息不清晰

## 审核步骤

1. **单据完整性检查**：核对7类单据是否齐全
2. **信息一致性检查**：申请单、审批表、发票、支付凭证之间的信息是否一致
3. **标准合规性检查**：人均费用、陪同人数、总金额是否符合标准
4. **风险点排查**：按高、中、低风险点逐项排查
5. **结论**：通过/不通过，并说明理由
