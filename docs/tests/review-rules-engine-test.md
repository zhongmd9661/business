## 一、cross_field_compare 表达式求值器

### 测试 1.1: 日期跨槽位比较
**输入**: 以下 `fields_by_slot` 模拟数据
```json
{
  "审批单": {"招待日期": "2026-02-27"},
  "申请单": {"申请日期": "2026-02-15"},
  "发票XML": {"开票日期": "2026-02-27"},
  "支付凭证": {"支付时间": "2026-02-28"},
  "支付流水": {"交易时间": "2026-03-01"},
  "报账单": {"报销日期": "2026-03-05"},
  "活动函件": {"交流时间": "2026-03-02"}
}
```

**规则表达式**:
```json
{
  "type": "cross_field_compare",
  "field": "招待日期",
  "field_slot": "审批单",
  "field_type": "date",
  "comparisons": [
    { "other_slot": "申请单", "other_field": "申请日期", "operator": "<=", "message": "申请日期应早于招待日期" },
    { "other_slot": "发票XML", "other_field": "开票日期", "operator": "<=", "message": "开票日期应不晚于招待日期" },
    { "other_slot": "支付凭证", "other_field": "支付时间", "operator": ">=", "message": "支付时间应不早于招待日期" },
    { "other_slot": "支付流水", "other_field": "交易时间", "operator": ">=", "message": "交易时间应不早于招待日期" },
    { "other_slot": "报账单", "other_field": "报销日期", "operator": ">=", "message": "报销日期应不早于招待日期" },
    { "other_slot": "活动函件", "other_field": "交流时间", "operator": "~", "tolerance_days": 7, "message": "活动函件日期应与招待日期相近" }
  ]
}
```

**预期输出**:
```
✅ 申请日期 2026-02-15 ≤ 招待日期 2026-02-27
✅ 开票日期 2026-02-27 ≤ 招待日期 2026-02-27
✅ 支付时间 2026-02-28 ≥ 招待日期 2026-02-27
✅ 交易时间 2026-03-01 ≥ 招待日期 2026-02-27
✅ 报销日期 2026-03-05 ≥ 招待日期 2026-02-27
✅ 活动函件日期 2026-03-02 与招待日期 2026-02-27 相差 3 天 (容差±7天)
passed: true
```

### 测试 1.2: 日期比较不通过场景
**修改申请单申请日期为 "2026-03-01"**(晚于招待日期)

**预期输出**:
```
❌ 申请日期 2026-03-01 > 招待日期 2026-02-27 (应早于)
passed: false
```

### 测试 1.3: 金额跨槽位比较
```json
{
  "type": "cross_field_compare",
  "field": "价税合计小写",
  "field_slot": "发票XML",
  "field_type": "number",
  "tolerance": 0.01,
  "comparisons": [
    { "other_slot": "审批单", "other_field": "招待金额", "operator": "==", "message": "审批单金额应与发票一致" },
    { "other_slot": "支付凭证", "other_field": "金额", "operator": "==", "message": "支付凭证金额应与发票一致" }
  ]
}
```

**输入数据**:
```json
{
  "发票XML": {"价税合计小写": 2500.00},
  "审批单": {"招待金额": 2500.00},
  "支付凭证": {"金额": 2500.50}
}
```

**预期输出**:
```
✅ 审批单金额 2500.00 == 发票金额 2500.00 (差 0.00)
❌ 支付凭证金额 2500.50 != 发票金额 2500.00 (差 0.50 > 容差 0.01)
passed: false
```

### 测试 1.4: 缺失槽位字段
**输入数据**: 缺少"支付流水"槽位
```json
{
  "审批单": {"招待日期": "2026-02-27"}
}
```

**规则包含** 支付流水的比较条件

**预期输出**:
```
⚠️ 跳过: 未找到槽位[支付流水]的字段[交易时间]
passed: true (跳过不算不通过)
```

## 八、槽位-字段映射表（动态可配置）

> **重要**: 槽位字段不是写死的，而是在「字段提取规则配置」页面 (`extraction-rules.html`) 动态管理的。
> 
> - 用户可以**新增/删除/修改**任意槽位的字段定义
> - 审核规则表单中的字段下拉框，**实时读取** `extraction_rules` 表中当前定义的字段
> - Excel 导入时，**不校验字段名是否存在**（允许先建规则、后建字段）
> - 审核执行时，如果某字段不存在，跳过该比较条件，**不算不通过**

### 默认字段定义（首次启动时种子数据）

有效槽位: 审批单 | 申请单 | 报账单 | 发票XML | 发票PDF | 经营状态 | 支付凭证 | 支付流水 | 活动函件

各槽位默认字段（可在「字段提取规则配置」中调整）:
- 审批单: 招待日期, 招待人数, 陪同人数, 人均费用, 招待金额, 招待类型, 招待对象, 事由
- 申请单: 申请日期, 事由, 预计费用, 参加人员
- 报账单: 发票金额, 税额, 合计金额, 报销日期
- 发票XML/发票PDF: 价税合计大写, 价税合计小写, 开票日期, 购买方, 销售方, 发票号码
- 经营状态: 单位名称, 经营状态, 是否异常
- 支付凭证: 交易单号, 商户单号, 金额, 商户全称, 支付时间
- 支付流水: 交易单号, 交易对方, 金额, 交易时间
- 活动函件: 活动名称, 交流时间, 参加人员

有效运算符:
- 日期: <=, >=, ==, !=, ~ (近似, 需容差)
- 数字: <=, >=, ==, !=, >, < (需容差)
