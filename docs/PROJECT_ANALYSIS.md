# 业务招待费智能审核系统 — 项目分析报告

> 生成时间：2026-07-25

---

## 一、项目概览

**业务招待费智能审核系统** — 面向中国移动广东清远分公司的企业财务报销自动化审核系统。核心目标是通过 OCR 识别单据文档，自动提取字段，然后按管理制度规则执行多维度审核并生成报告。

| 属性 | 值 |
|------|-----|
| 项目名 | ocr-pipeline (v0.1.0) |
| 语言 | Python 3.11+ |
| 源码规模 | ~8,674 行 Python |
| 测试文件 | 31 个 |
| 运行平台 | Windows 11 + NVIDIA GPU (CUDA) |

## 三、核心架构（5 阶段流水线）

```
┌─────────────┐      ┌──────────────┐      ┌──────────────┐      ┌────────────┐      ┌────────────┐
│  ① 扫描文档  │ ──→  │ ② OCR 识别  │ ──→  │ ③ 字段提取  │ ──→  │ ④ 规则审核  │ ──→  │ ⑤ 审核报告  │
│  (PDF/图片)  │      │ (MinerU 引擎) │      │ (正则/LLM)  │      │ (34+条规则)  │      │ (文本+Markdown)│
└─────────────┘      └──────────────┘      └──────────────┘      └────────────┘      └────────────┘
```

### ① 文件收集 (`batch_processing/collector.py`)

- 支持 PDF / 图片 / XML / Office 文档
- ZIP 解压、按 `###_` 三位序号排序
- XML 全电发票走直通路径（不经过 OCR 引擎）

### ② OCR 识别 (`document_parsing_pipeline/`)

- MinerU LocalAPIServer，HTTP 异步调用
- 输出 Markdown 文本，JSON / 图片分离
- 支持 GPU 加速（CUDA 11.8 + cuDNN 8.9.7）

### ③ 双引擎字段提取 (`expense_review_comprehensive/`)

- **规则提取器**（默认）：正则表达式 + HTML/Markdown 表格解析
- **LLM 提取器**（可选）：通过 Anthropic 兼容 API 调用大模型，环境变量 `USE_LLM_EXTRACTOR=1` 切换

### ④ 规则审核（34+ 条规则，7 个 Checker）

| Checker | 规则数 | 示例规则 |
|---------|--------|----------|
| 单据完整性 | 7 | 报账单号一致性、支付凭证(2024-04后强制)、往来公函(2025-12后外部强制)、发票查验、网格分摊表签章 |
| 金额标准 | 5 | 外部招待矩阵(人员层级×招待类型)、内部招待(150/100元)、工作餐(60元)、酒水单价(100元)、纪念品(200元) |
| 招待类型与陪同人数 | 3 | 党政军→其他公务匹配、外部≤5对等/>5超一半、内部≤10时3人/>10时1/3 |
| 禁止性规定 | 6 | 高档场所、高档菜品、烟酒、批量购买、公款送礼、变相旅游 |
| 报销合规 | 6 | 事前审批、大额现金(>5000)、拆分报销、混淆费用、发票类型、预存签单 |
| 交叉稽核 | 4 | 企业经营状态、节日招待报备、重复招待、差旅期间招待 |
| 校对规则 | 6 | 金额一致性、日期一致性、招待标准、单位状态、支付凭证一致性、活动函件日期 |

严重级别分为四级：**高 → 中 → 低 → 提示**

### ⑤ 报告生成 (`reporter.py`)

- 文本格式 (`审核报告.txt`) + Markdown 格式 (`审核报告.md`) 双输出
- Markdown 报告含字段对比表
- 高风险通过 Webhook 告警通知 (`WebhookNotifier`)

## 五、Web 服务架构

基于 FastAPI，提供完整的在线交互体验。

### API 路由

| 路由模块 | 功能 |
|----------|------|
| `router.py` | 文件上传、任务管理、异步处理流水线 |
| `router_rule.py` | 规则管理（CRUD） |
| `router_standards.py` | 报销标准查询 |
| `router_standards_admin.py` | 标准设置（管理员密码保护） |
| `router_application_form.py` | 审批单/报账单表单生成 |
| `router_reception_records.py` | 接待记录管理 |
| `router_qichacha.py` | 企查查 API 集成 |

### UI 页面

| 页面 | 路径 | 说明 |
|------|------|------|
| 主页 | `/ui-index` | 首页入口 |
| 文件上传 | `/upload` | 上传单据文件 |
| 智能审核 | `/audit` | 在线审核 |
| 提交记录 | `/records` | 查看历史记录 |
| 参考资料 | `/reference` | 制度文档参考 |
| API 文档 | `/docs` | Swagger UI |
| 健康检查 | `/api/health` | 服务状态 |

### 认证体系

- **JWT Token** 认证，`python-jose` 签发，`bcrypt` 密码哈希
- **角色权限**：user / admin，管理员路由单独鉴权
- **用户注册/登录**：`/api/auth/register` 和 `/api/auth/login`

### 异步处理

- 上传文件后通过 `asyncio.create_task` 启动异步流水线
- OCR 限流 `Semaphore(3)`，最多 3 个并发任务
- 任务状态通过 `/api/tasks/{id}` 轮询查询

## 六、规则体系

### 规则来源

基于《中国移动广东公司清远分公司业务招待费管理办法（V9.0）》及审查风险点清单，所有规则均标注对应制度条款。

### 时间线规则

审核规则根据招待日期自动切换：

| 时间节点 | 规则变化 |
|----------|----------|
| 2024-04-01 后 | 必须附带支付凭证 |
| 2025-06-01 前 | 需手动发票查验证明，之后系统校验即可 |
| 2025-09-01 后 | 必须附带支付流水证明 |
| 2025-12-04 后 | 外部招待必须附带往来公函 |

### 金额标准矩阵

**外部招待**：人员层级 × 招待类型 → 人均上限

| 层级 | 外事/商务 | 其他公务 |
|------|-----------|----------|
| 省管中层 | 400 元 | 250 元 |
| 市管中层 | 300 元 | 200 元 |
| 其他人员 | 250 元 | 150 元 |

**内部招待**：省管/市管中层 150 元，其他人员 100 元
**工作餐**：60 元/人
**酒水单价**：≤ 100 元
**纪念品**：≤ 200 元/人

## 七、亮点设计

1. **时间线规则** — 审核标准根据招待日期自动切换，而非硬编码死逻辑
2. **批次聚合** — 同批次文档属于同一笔事件，金额取优先级链（发票→报账单→审批单），避免重复计算
3. **双引擎提取** — 正则引擎零依赖快速运行，LLM 引擎更高精度，通过环境变量无感切换
4. **动态规则加载** — LLM 提示词从 `skill/` 目录动态读取，制度更新无需改代码
5. **规范驱动开发** — 使用 OpenSpec，变更均有提案、设计、规范和任务跟踪
6. **跨文档校对** — 独立校对 Checker 模块（861 行），覆盖金额/日期/标准等 6 个一致性维度

## 九、潜在改进方向

| 方面 | 建议 | 优先级 |
|------|------|--------|
| **企业经营状态** | 当前为占位提示，可对接企查查 API（已有 `router_qichacha.py` 模块） | 高 |
| **差旅数据关联** | 8.4 差旅期间招待校验仍为人工提示，需与差旅系统打通 | 高 |
| **并发处理** | OCR 限流 semaphore 为 3，大批量时可评估调优 | 中 |
| **前端框架** | 当前为纯 HTML/JS，考虑 SPA 框架（Vue/React）提升可维护性 | 中 |
| **数据库** | SQLite 适合单机，生产环境建议迁移 PostgreSQL | 中 |
| **安全加固** | CORS 当前为 `allow_origins=["*"]`，生产环境应限制域名 | 高 |
| **CORS 安全** | 生产环境建议收紧为具体域名白名单 | 高 |
| **任务持久化** | 当前 `task_queue` 为内存字典，服务重启丢失，建议持久化 | 中 |

## 十、运行方式

### 方式一：CLI 批量处理

```powershell
# 准备材料
Copy-Item "01业务招待费材料案例\某批次" "data\input\" -Recurse

# 运行审核
.venv\Scripts\python.exe -m scripts.batch_parse --once

# 查看结果
# data/已识别/<批次名>_<时间戳>/审核报告.md
```

### 方式二：Web 服务在线审核

```powershell
# 启动服务（默认 8099 端口）
python start_server.py

# 或手动启动
.venv\Scripts\python.exe -m uvicorn src.web_service.app:app --host 0.0.0.0 --port 8006

# 浏览器访问 http://localhost:8099/ui-index
```
