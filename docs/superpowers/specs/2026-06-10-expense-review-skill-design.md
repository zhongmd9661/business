# 业务招待费审核 Skill 设计

## 概述

在 OCR 批量解析完成后，自动对识别结果按审查规则逐项检查，生成审核报告并通过 webhook 通知。

## 架构

```
batch_parse.py 完成
    │
    ▼
┌─────────────────────────┐
│  Hook 触发 review skill  │  ← 解析完成后自动调用
├─────────────────────────┤
│  1. 读取识别结果目录      │
│  2. 加载审查规则          │
│  3. 逐文档审核            │
│  4. 生成审核报告          │
│  5. 发送通知              │
└─────────────────────────┘
    │
    ▼
data/已识别/{批次}/审核报告.md
```

Skill 定义在 `.claude/skills/generate-expense-review-skill/SKILL.md`，通过 `batch_parse.py` 末尾的 hook 调用。

## 审查规则

### 明确规则（可程序化验证）

- 发票日期 = 招待日期
- 发票金额 <= 招待标准
- 陪同人数不超标（≤5人对等，>5人超1/2）
- 招待日期 >= 申请日期
- 2025/6/1 后无需发票查验
- 2024/4/1 起支付凭证 100%
- 2025/12/4 起外部招待必需往来公函

### 模糊规则（需 LLM 判断）

- 招待事由是否合理
- 是否存在虚假招待迹象
- 招待对象与招待类型是否匹配
- 来宾单位经营状态
- 是否重大节日期间安排招待

规则存储在 SKILL.md 的提示词中，便于随时调整。

## 输出

### 审核报告

```
data/已识别/{批次}/
├── 识别结果/
│   ├── 001_xxx.md
│   ├── 001_xxx.json
│   └── ...
├── 源文件/
└── 审核报告.md              ← 新增
```

### 报告结构

```markdown
# 业务招待费审核报告

## 批次信息
- 批次: xxx
- 时间: 2026-06-10
- 文档数: 5

## 审核结果总览
- 通过: 3 | 风险: 2

## 逐文档审核

### 001_xxx.md
- [通过] 发票日期与招待日期一致
- [风险] 陪同人数超标: 招待对象 3 人, 陪同 4 人
- [提示] 招待事由描述模糊, 建议补充

## 风险汇总
| 风险等级 | 数量 | 说明 |
|---------|------|------|
| 高 | 1 | 人数超标 |
| 中 | 1 | 事由模糊 |
```

### 通知

通过企微/钉钉 webhook 发送摘要（批次、文档数、风险数）。
