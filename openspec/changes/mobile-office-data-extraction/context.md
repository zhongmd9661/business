# Change Context & Decision Log

本文件用于记录 `mobile-office-data-extraction` 变更过程中的所有重要讨论、用户需求变更及技术决策。

## 2026-07-08: 初始化与方案对齐
- **需求**: 采集 Win11 “移动办公” 窗口程序数据（含指标卡片和表格）。
- **参考**: 参考 `mobile-sim-recognition` 的视觉重建方案。
- **当前状态**: 已完成 `proposal.md`, `design.md`, `tasks.md` 的编写。
- **约定**: 所有相关的对话 and 决策均需同步写入此文件，以保持上下文一致性。
- **技术关键点**: 用户强调传统 OCR 无法处理水印干扰，而大模型（VLM）能够有效排除水印影响直接识别数据。这进一步验证了采用 VLM 解析管线的必要性。
- **交互细节**: 目标程序无可见滚动条。上下滑动通过鼠标滚轮实现；左右滑动需按住左键拖拽。由于缺乏滚动条坐标，拼接必须完全依赖视觉语义指纹。
