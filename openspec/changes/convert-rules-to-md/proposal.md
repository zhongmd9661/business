## 问题

审核系统使用的规则依据（业务招待费管理办法、审查风险点）存储在 `00规则制度/` 目录下，格式为 .docx。这些文件需要转换为 Markdown 格式以便：

1. 在 Obsidian 等 Markdown 笔记系统中直接阅读和链接
2. 作为审核系统的参考文档被程序读取
3. 与项目的其他 Markdown 文档保持一致

## 方案

使用 MinerU 引擎（项目已有的文档解析能力）将 `00规则制度/` 下的 .docx 文件解析为 Markdown，输出到 `00规则制度_md/` 目录。

## 范围

- 输入：`00规则制度/` 下的所有 .docx 文件（2 个）
- 输出：`00规则制度_md/` 下的 .md 文件
- 工具：MinerU 引擎（复用 `batch_parse.py` 中的解析逻辑）
