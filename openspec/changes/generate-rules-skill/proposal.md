## 摘要

本变更旨在建立规则制度与批次审核之间的关联机制。通过为 `00规则制度/` 的每个子文件夹生成对应的 Claude Code skill，并制定批次文件夹命名规则，使批次自动关联到相应的审核规则。最终为每个批次生成一个整合的 `待审核.md` 文件，将规则与 OCR 识别结果合并，供 AI 直接对照审核。

## 问题

审核系统的规则依据散落在 `00规则制度/` 子文件夹中的 Word 文档中，已有 Markdown 转换版本存放于 `00规则制度_md/`。AI 审核时无法自动加载这些规则作为上下文。同时，每个批次的 OCR 识别结果分散在多个 MD 文件中，不利于审核时整体查看。

## 方案

1. 扫描 `00规则制度/` 的子文件夹，为每个子文件夹生成一个对应的 Claude Code skill，skill 名称与子文件夹名称一致（如 `00综合部业务招待费` → `skill/00综合部业务招待费/SKILL.md`）
2. Skill 内容从 `00规则制度_md/` 中对应的 Markdown 文件整理而来
3. **命名规则**：批次文件夹名格式为 `<skill名称>_<批次类型>_<摘要>_<日期>_<时间戳>`，例：`00综合部业务招待费_审核_广信君达律所法律交流_20260611_151211`，前缀直接对应 skill 名称
4. 为每个批次生成整合的 `待审核_<批次名>.md`：文件名与批次文件夹名完全一致，嵌入匹配的 skill 规则 + 按 skill 单据类型分类的 OCR 识别结果

## 命名规则

| 元素 | 说明 | 示例 |
|------|------|------|
| Skill 名称 | `00规则制度/` 子文件夹名 | `00综合部业务招待费` |
| 批次类型 | 审核/识别/归档等 | `审核` |
| 摘要 | 批次用途简述（方便了解批次内容） | `广信君达律所法律交流` |
| 日期 | YYYYMMDD | `20260611` |
| 时间戳 | HHmmss | `151211` |
| 完整批次名 | `<skill名称>_<批次类型>_<摘要>_<日期>_<时间戳>` | `00综合部业务招待费_审核_广信君达律所法律交流_20260611_151211` |

根据批次文件夹名前缀即可自动关联到对应的 skill。

## 范围

- 输入：`00规则制度/` 下的子文件夹（当前：`00综合部业务招待费`），对应读取 `00规则制度_md/` 中的 Markdown 转换文件
- 输出1：`skill/<子文件夹名>/SKILL.md` — 每个子文件夹对应一个 skill
- 输出2：每个批次目录下的 `待审核_批次名.md` — 嵌入 skill 规则 + 按 skill 单据类型分类的 OCR 识别结果
- 关联机制：批次文件夹名前缀 = skill 名称；文件夹名中的摘要部分方便快速了解批次用途
