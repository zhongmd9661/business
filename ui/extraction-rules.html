说明

• 字段名：提取后输出的字段名称
• 关键词：在 OCR 文本中搜索的关键词（逗号分隔多个，按顺序匹配，匹配到第一个即返回）
• 类型：text 纯文本 / number 提取数字 / date 解析为日期
• 匹配模式：支持 关键词: 值、关键词 = 值、| 关键词 | 值 | 等格式

LLM 提取说明

• 大模型提取利用 LLM 的语义理解能力，对非结构化文档的提取效果通常优于关键词匹配
• 提取的字段定义与关键词规则共享（上方的字段列表）
• 大模型地址、API Key、模型名称等在 系统设置 中统一配置
• 启用后，OCR 完成时会自动使用 LLM 进行字段提取
• 可在预览测试中对比 "关键词预览" 和 "LLM 预览" 的效果差异
